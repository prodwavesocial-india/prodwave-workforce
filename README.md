

# Prodwave Workforce Attendance Portal 

A simple, responsive employee attendance webpage for Prodwave, designed to make daily employee activities easy to access and manage.

##  Live Website

Once GitHub Pages is enabled, your website will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/prodwave-workforce/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.

##  Features

- **Employee Portal:** Personalized dashboard with employee name.
- **Check In / Check Out:** Quick access to the attendance Google Form.
- **Attendance Dashboard:** Displays the latest attendance action and time.
- **Working Hours:** Tracks working duration based on check-in and check-out.
- **Attendance History:** Stores recent attendance activity in the browser.
- **Quick Actions:** Direct links to important employee and client forms.
- **Live Digital Clock:** Displays the current time in 24-hour format and date.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Prodwave Branding:** Includes company logo and employee-focused design.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

##  How to Deploy Using GitHub Pages

1. Open your GitHub repository.
2. Navigate to **Settings**.
3. Select **Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main`.
6. Select folder `/ (root)`.
7. Click **Save**.
8. Wait for GitHub Pages to publish your website.

## Important Notes

- Attendance history and employee information are stored in the browser using Local Storage.
- Data is specific to the browser and device being used.
- Clearing browser data may erase locally stored attendance records.
- Attendance records are not automatically shared with a central database.
- Google Form submissions are separate from the local attendance dashboard.
- For centralized employee attendance tracking, integration with Google Sheets or a database is recommended.

##  Privacy & Security

This project is a front-end attendance interface. Do not store passwords, confidential employee information, API keys, or other sensitive data in the public GitHub repository.
